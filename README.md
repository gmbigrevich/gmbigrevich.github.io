## 🔒 Implementaciones de Seguridad (Hardening Web)

# Utilizo la IA (Kimi3, Gemini Pro Extended, Perplexity) para verificar potenciales vulnerabilidades y exploits en cada código que realizo, luego los analizo y comparo para una retroalimentación que fortalezca mi aprendizaje. Éste repositorio es un ejemplo de las politicas y mitigaciones que pude implementar, desde la experiencia y aprendizaje hasta el hardening utilizando herramientas IA y criterio propio.
*   **Content Security Policy (CSP):** Etiqueta estricta implementada para mitigar XSS bloqueando scripts no autorizados.
*   **Mitigación de Reverse Tabnabbing:** Enlaces salientes protegidos con `target="_blank" rel="noopener noreferrer"`.
*   **Ofuscación Anti-Scraping:** La dirección de contacto se construye bajo demanda mediante JavaScript, evitando recolección de bots.
*   **Modo Estricto:** Código JS ejecutado con `'use strict'` para evitar comportamientos inseguros.
